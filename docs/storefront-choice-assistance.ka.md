# არჩევანში დახმარება — ფრონტის მესამე ეტაპი

**27 ნოემბერი 2026**

მიზანი: მყიდველმა საინტერესო პროდუქტები შეაგროვოს, განსხვავებები გასაგებად დაინახოს და ნაწილის არჩევისას იცოდეს, რას ადასტურებს კატალოგი და რა არის დასაზუსტებელი. მოდულები აგრძელებს [მაღაზიის ერთიანი გამოცდილების პრინციპებს](storefront-experience-principles.ka.md).

## მომხმარებლის გზა

ბარათსა და პროდუქტის გვერდზე ხელმისაწვდომია შენახვა და შედარება. ორივე არჩევანი ჩანს საერთო მენიუში და ნარჩუნდება გვერდებს შორის გადაადგილებისას.

| შესაძლებლობა | ქცევა |
|---|---|
| შენახვა | სხვადასხვა ტიპის მაქსიმუმ 50 პროდუქტი; რეგისტრაცია საჭირო არ არის |
| შენახულის გვერდი | მოქმედი ფასი, ხელმისაწვდომობა, ტიპის მიხედვით ნახვა, ამოღება და ბოლო ამოღების დაბრუნება |

| განსხვავებები | განსხვავებული რიგები მონიშნულია; შესაძლებელია მხოლოდ განსხვავებების დატოვება |

შენახვა პროდუქტის დაჯავშნას, ფასის დაფიქსირებას ან მარაგის არსებობის დაპირებას არ ნიშნავს.

## მონაცემების წესები

ბრაუზერში ინახება მხოლოდ ვერსიონირებული იდენტიფიკატორები, თითოეული მაღაზიის ცალკე გასაღებით. სახელები, ფოტოები, ფასები, ხელმისაწვდომობა და მახასიათებლები მაღაზიის გამოქვეყნებული კატალოგიდან მოდის. პირადი მონახაზები და სარედაქციო შემოწმების მონაცემები ამ გზით არ გაიცემა.

კატალოგიდან გამქრალი ჩანაწერი სიიდან ჩუმად არ ქრება: მომხმარებელი ხედავს რამდენი პროდუქტი აღარ არის ხელმისაწვდომი და თავად შეუძლია ჩანაწერების ამოღება. ძველი ფასი და მახასიათებლები მის ნაცვლად არ ჩანს. ჩატვირთვის შეცდომა არჩევანს არ შლის და აქვს ხელახალი ცდა.

არჩევანი იმავე ბრაუზერსა და მოწყობილობაზე რჩება. ანგარიშით სინქრონიზაცია ამ მოდულს არ აქვს. ბრაუზერის მონაცემების წაშლა არჩევანსაც შლის. თუ მუდმივი შენახვა დაბლოკილია, არჩევანი ამ გვერდის სესიაში მუშაობს; ინტერფეისი განმარტავს, რომ განახლების ან დახურვისას დაიკარგება.

ერთი მაღაზიის სხვადასხვა ჩანართი არჩევანს იზიარებს. დაგვიანებული შეტყობინება უფრო ახალ ადგილობრივ ცვლილებას უკან არ აბრუნებს. რამდენიმე ტაბიდან ზუსტად ერთდროული ცვლილებისთვის ბრაუზერის საცავი ტრანზაქციული სერვერის შემცვლელი არ არის.

## შედარების მნიშვნელობა

- მახასიათებლები ერთიანდება მათი **გასაღებით**. წყაროს მნიშვნელობები და ერთეულები ინარჩუნებს მნიშვნელობას; ცხენის ძალა და კვტ თვითნებურად არ გადაითვლება.
- „არ არის მითითებული“, ნული და „არა“ განსხვავებული მდგომარეობებია.
- ზედმეტი გამოტოვებები განსხვავებად არ ითვლება; ასოების რეგისტრი და ერთეულის განსხვავება შენარჩუნებულია.
- „მხოლოდ განსხვავებები“ წყაროს შევსებულობასაც ასახავს. ერთი პროდუქტის დარჩენისას ყველა მახასიათებელი ჩანს.
- მახასიათებლების თანხვედრა იდენტურობას, ურთიერთჩანაცვლებადობას ან კონკრეტული მომხმარებლისთვის „საუკეთესო“ არჩევანს არ ადასტურებს.
- შერეული ტიპების შემცველი გაზიარებული ან ძველი შენახული არჩევანი აჩვენებს გამოსწორების გზას; შეცდომაში შემყვანი საერთო ცხრილი არ იქმნება.

ცხრილი დამოუკიდებელ ჩარჩოში გადაადგილდება. პროდუქტის სახელები და მახასიათებლების დასახელებები ადგილზე რჩება. ვიწრო ეკრანზე ერთი პროდუქტის სვეტი და მისი დასახელებები ერთად იკითხება; მთელი გვერდი გვერდზე არ უნდა გაიწიოს. ცხრილს აქვს კლავიატურით მართვა და სემანტიკური სტრიქონისა და სვეტის სათაურები.

## თავსებადობის მნიშვნელობა

პროდუქტის გვერდი აჩვენებს წყაროში არსებულ ტიპებს, ბრენდებს, საბურავის ზომას, ძრავის მოდელსა და შენიშვნას. კონკრეტული პროდუქტის კავშირი გაიცემა მხოლოდ არსებული ჩანაწერით და მხოლოდ გამოქვეყნებულ სამიზნეზე.

| კავშირი | რას ნიშნავს წარმოდგენაში |
|---|---|
| `fits` | კატალოგში კონკრეტულ მოდელთან მითითებული კავშირი და მისი არსებული მიზეზი |
| `same_size` | ზომის თანხვედრა; სრული თავსებადობის დასტური არ არის |
| `variant` | დაკავშირებული სხვა ვარიანტი; ავტომატური პირდაპირი შემცვლელი არ არის |
| `spare_part` | დაკავშირებული ნაწილი; ზუსტი მოდელი, კოდი და ზომა შესამოწმებელია |
| `accessory` | დაკავშირებული დანადგარი ან აქსესუარი; შეერთება და მონტაჟი კონკრეტულ პროდუქტთან მოწმდება |
| `consumable` | დაკავშირებული სახარჯი მასალა; დანიშნულება და საჭირო პარამეტრები შესადარებელია |

ზოგადი ტიპი ან ბრენდი ყველა მოდელთან თავსებადობას არ ნიშნავს. კავშირი უკუმიმართულებით არ გამოიცნობა. კომპონენტს, რომელსაც ინფორმაცია აკლია, აქვს მოდელის/კოდის/ზომის დაზუსტებისა და კონტაქტის გზა. ჩვეულებრივ ძირითად მოწყობილობას ცარიელი თავსებადობის გაფრთხილება არ ემატება.

## საერთო მოდულები და ადმინისტრირება

შენახვა და შედარება ადმინისტრატორის ბლოკების რიგზე ან გამორჩეულ კატეგორიებზე არ არის დამოკიდებული. იგივე კონტროლები მუშაობს მთავარის, კატეგორიისა და დაკავშირებული პროდუქტების ბარათებზე. მოქმედებები პროდუქტის ბმულის გარეთაა, რათა შენახვის დაჭერამ პროდუქტის გვერდი შემთხვევით არ გახსნას.

მთავარის პირადი წინასწარი ხედი ბარათის ზომებს ინარჩუნებს; შენახვისა და შედარების კონტროლები იქ გამორთულია და მყიდველის სიებს არ ცვლის. კომპოზიცია, ფოტო და შინაარსი კვლავ არსებული ადმინისტრაციული წესებით იმართება.

მომავალი ბრენდი ცვლის ვიზუალურ ხასიათს, მაგრამ ინარჩუნებს შენახვისა და შედარების მნიშვნელობას, მოქმედ მონაცემებს, უცნობი ფაქტის აღნიშვნას და შეცდომიდან გამოსვლის გზას.

## შემოწმების სცენარები

ქვემოთ მოთხოვნებია. შესრულებული ტესტები, გარემო და შედეგები გამოშვების PR-ში აღირიცხება. რეალური ტელეფონი და ბრაუზერის ვიწრო ხედი ცალ-ცალკე ფასდება.

- [ ] ბარათიდან და პროდუქტიდან შენახვა აისახება მენიუში, სიაში და განახლების შემდეგ.
- [ ] ამოღება, დაბრუნება და ბოლო ელემენტის ამოღება ინარჩუნებს მდგომარეობასა და ფოკუსს.
- [ ] იგივე ტიპის 2–4 პროდუქტი შედარდება; მეხუთე ან სხვა ტიპი არსებულ არჩევანს არ შლის.
- [ ] დაკარგული მონაცემი განსხვავდება ნულისა და „არა“-სგან; წყაროს ერთეულები არ იცვლება.
- [ ] „მხოლოდ განსხვავებები“ მუშაობს, მათ შორის ერთი პროდუქტის დარჩენისას.
- [ ] გაზიარებული ბმული პირად შედარებას ცალკე მოქმედების გარეშე არ ცვლის.
- [ ] გამოუქვეყნებელი პროდუქტი, შეცვლილი ფასი, გაფუჭებული ჩანაწერი და დაბლოკილი საცავი სწორად მუშავდება.
- [ ] 340 px, 390 px და დესკტოპის ხედში კონტროლები გამოსაყენებელია და გვერდს ჰორიზონტალური გადაცდენა არ აქვს.
- [ ] პირადი წინასწარი ხედიდან ვერ იცვლება მომხმარებლის შენახული სია ან შედარება.
- [ ] ძიება, ფილტრები, კალათა, გამოქვეყნება და შეკვეთის ლოგიკა გადის თავის რეგრესიულ შემოწმებებს.
