# მთავარი გვერდის პოლიტიკა — განხორციელების მდგომარეობა

27 ნოემბერი 2026 · სამუშაო განშტოება `feat/homepage-governance`

ეს ჩანაწერი აკავშირებს [მართვის პოლიტიკის](homepage-management-policy.ka.md) R01–R43 მოთხოვნებს ამ განშტოების კოდთან და ავსებს პოლიტიკის მე-10 ნაწილს. იგი აღწერს განხორციელებულ შესაძლებლობებს, შემოწმების ფარგლებსა და დარჩენილ დამოკიდებულებებს. **ეს არ არის ცოცხალ მაღაზიაზე დანერგვის ან გაყიდვების ზრდის დადასტურება.**

სტატუსები: **კოდში** — შესაძლებლობა განხორციელებულია ამ განშტოებაში; **ნაწილობრივ** — არსებობს კონკრეტული შეზღუდვა ან მონაცემებზე დამოკიდებულება; **შემდეგი ეტაპი** — შესაბამისი შესაძლებლობა ამ ცვლილებაში არ დამატებულა. ტესტის არსებობა და რეალურ მომხმარებლებთან ვარგისიანობა ცალ-ცალკე ფასდება.

## 3 მონაცემებზე დამოკიდებული გაგრძელება

- **ხიდის მარაგი და მედია.** საჭიროა მარაგის სანდო, რეგულარული განახლება და პროდუქტის ფოტოების სრული მიწოდება. მიმდინარე `confirm_with_store` რჩება დასაზუსტებელ მდგომარეობად; „მხოლოდ დადასტურებული მარაგი“ ასეთი პროდუქტებისგან შერჩევას დაცლის. ფოტო-მითითების არსებობა ფიზიკური ფაილის არსებობას არ უდრის. მთავარი გვერდის ფოტოს ატვირთვა პროდუქტის წყაროს მედიის სინქრონიზაციას არ ანაცვლებს.
- **სარედაქციო მზადყოფნა.** ადმინისტრატორმა უნდა გადაამოწმოს კატეგორიების დიაპაზონი, რეალური ტექნიკური მახასიათებლები, ფოტო, თავისუფალ ტექსტში თანხა/პროცენტი და მომსახურების პირობები. ავტომატური წესები არ ამოწმებს ყველა მარკეტინგული წინადადების ფაქტობრივ სისწორეს.
- **გაზომვა და ადამიანებთან შემოწმება.** ჯერ საჭიროა მოვლენების განსაზღვრა, სესიების/შეკვეთების სანდო დაკავშირება, რეალური მომხმარებლების ტექნიკური საზომები და ადმინისტრატორისა და მყიდველის დავალებებით გამოცდა. ამის შემდეგ შეფასდება კონვერსია და კონკრეტული ცვლილების შესაძლო გავლენა.
