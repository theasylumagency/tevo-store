# Standard Store 2.0 — Foundation & Trust / პირველი ცვლილება

ეს არის ბრენდისგან დამოუკიდებელი სტანდარტული მაღაზიის ცვლილება. rodo.ge სამუშაო გარემოა; ბრენდის დიზაინი, პოზიციონირება და კონტენტი არ იცვლება.

**მიზანი:** გავზარდოთ ადამიანისთვის სასარგებლო გადაწყვეტილების მიღების ალბათობა. მომხმარებელს სასარგებლო გზა რჩება მაშინაც, როდესაც შეძენა ჯერ შეუძლებელია.

## ამ ცვლილების მიღების პირობები

- `confirm_with_store` ნიშნავს დასაზუსტებელ მარაგს: პირდაპირი შეძენა აკრძალულია, კონტაქტი, ალტერნატივები, შენახვა და შედარება ხელმისაწვდომია. ადრე კალათაში დამატებული პროდუქტი რჩება, მაგრამ შეკვეთა იბლოკება.
- უცნობი მიწოდების საფასური ნული არ არის. თვითგატანა შესაძლებელია; უცნობი მიწოდებით ჩვეულებრივი შეკვეთა არც ნაღდი და არც ონლაინ გზით არ იქმნება. კალათა რჩება, კონტაქტის გზით შეიძლება სრული პირობების დაზუსტება.
- ძველ, გაურკვეველი მიწოდების საფასურის მქონე გადაუხდელ შეკვეთაზე ახალი გადახდა არ იწყება. განმეორებითი გადახდისას მოწმდება მიმდინარე ხელმისაწვდომობაც.
- რეალურად დაუნერგავი საბანკო ადაპტერები არ ჩანს გადახდის ვარიანტებად, თუნდაც გასაღებები იყოს კონფიგურირებული.
- ფრონტის შეზღუდვა სერვერზე მეორდება; თანხა, პროდუქტი და სტატუსი მაღაზიის მოქმედი პუბლიკაციიდან მოდის.

## საზღვრები

ეს არ არის ფიზიკური მარაგის ჯავშანი ან ხიდთან ატომური საერთო მარაგის კონტროლი. სრული შეთავაზების მოთხოვნის ცალკე ჩანაწერი/ადმინის პროცესი, მიწოდების ტარიფები და რეალური ბანკების ინტეგრაცია ცალკე სამუშაოა. მანამდე უცნობი მიწოდების შემთხვევაში უსაფრთხო ალტერნატივა კონტაქტის გვერდი ან თვითგატანაა. კატალოგის საწყისი მარაგები არ შეცვლილა; თუ ყველა პროდუქტი დასაზუსტებელია, პირდაპირი გაყიდვა არ უნდა გააქტიურდეს, სანამ წყარო არ დაადასტურებს. სამართლებრივი ტექსტები გამოქვეყნებამდე იურისტის მიერ გადამოწმებას საჭიროებს. ანალიტიკის საწყისი ფენა შემდეგი ცალკე ცვლილებაა.

## შემოწმება

`npm run test:catalog` მოიცავს სერვერის უარყოფით სცენარებს და ამოწმებს, რომ არც შეკვეთა და არც გადახდა არ იქმნება. `npm run test:catalog-ui` იყენებს იზოლირებულ კატალოგს, არა წარმოების მარაგის ჩანაწერის შეცვლას. PR-ის CI შედეგი და რეალურ გარემოში შემდგომი მიღების ტესტი ცალკე დასადასტურებელია.
